Cómo se juega

Acomodá las piezas que caen para completar filas: cada fila completa desaparece. La sombra muestra dónde va a caer la pieza.

Controles: los botones de abajo, o sobre el tablero: tocar gira, deslizar a los lados mueve, deslizar hacia abajo suelta. Tocá «guardar» para reservar una pieza. En computadora: flechas, espacio para soltar y C para guardar.

Libre: velocidad fija a elección y sin fin: si se llena el tablero, se vacía y seguís.

Desafío: cada 10 líneas sube el nivel y la velocidad. Una sola partida: si se llena, se termina. Se guarda tu récord.
